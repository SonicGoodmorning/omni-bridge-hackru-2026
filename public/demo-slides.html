Live Gemini processing

Two calls, one review step

First call

Explain source paragraphs or translate a human turn into the target language.

Fresh second call

Render only the generated target text back into the original language.

The second call never receives the original source or conversation history.

The same model can repeat an error. Reverse rendering is a review aid.08
The Next.js server calls Gemini through @google/genai and validates structured output with Zod. The model ID is configurable, with current configuration recorded in the repository. The key is server-side. Calls share a 45-second overall deadline. Mechanical checks and reverse rendering do not establish medical accuracy or independent professional review.
